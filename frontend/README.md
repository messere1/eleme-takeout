# 轻量级外卖服务平台 - 前端

天津大学软件学院软件工程（系列）综合实践项目的前端仓库。项目参考“饿了么”核心业务流程，采用前后端分离架构完成一个轻量级外卖服务平台。

> 当前状态：项目初始化阶段，暂未开始业务代码开发。

## 课程信息

- 实践周期：2026-08-31 至 2026-09-20（共 3 周）
- 项目名称：轻量级外卖服务平台（仿饿了么）
- 开发方式：全程遵循 TDD（测试优先开发）
- 协作方式：Git 版本管理、小组协作、跨组交叉验收

## 前端职责

- 用户注册、登录与个人信息维护
- 店铺列表、店铺详情及营业状态展示
- 商品分类、商品列表、商品详情、价格与库存展示
- 购物车增删改查
- 订单确认、创建、列表与状态展示
- 公共导航、空状态、弹窗和异常提示等可复用组件
- 与后端 REST API 联调及验收材料整理

## 计划技术栈

- Vue 3
- Vue Router
- Element Plus（Vue 3 对应的 Element UI 生态组件库）
- Axios
- Vitest（前端测试，具体方案由小组确认）

技术选型目前仅作为课程任务建议，正式开发前由小组共同确认并记录设计决策。

## 架构约定

- 按页面、公共组件、路由、状态和 API 模块组织代码。
- 统一封装 Axios 请求、响应拦截和错误处理。
- 后端接口统一使用 `/api/v1` 前缀。
- 分页、过滤和排序参数通过 Query 参数传递。
- 以统一响应结构 `code`、`msg`、`data` 对接后端。

## TDD 与提交规范

每项功能遵循以下顺序：

1. 梳理需求与验收行为。
2. 编写正常、异常和边界场景测试。
3. 运行测试并确认失败。
4. 编写最小实现使测试通过。
5. 重构并执行回归测试。
6. 分阶段提交，保留“红 - 绿 - 重构”的 Git 记录。

禁止先集中完成全部功能后再补测试或一次性上传代码。

## 三周计划

| 阶段 | 时间 | 目标 |
| --- | --- | --- |
| 第 1 周 | 基础需求 | 搭建架构，完成用户、店铺、商品、购物车和基础订单页面及测试 |
| 第 2 周 | 需求迭代 | 针对需求变更补充测试、适配接口并完成回归测试 |
| 第 3 周 | 完善验收 | 重构、优化交互与异常提示，整理测试和交叉验收材料 |
