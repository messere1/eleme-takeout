## 3. 尚缺或未闭环的覆盖

1. 商家商品新增、编辑、删除、上下架和库存管理页面尚未形成完整前端功能，无法完成端到端页面测试；后端契约和服务测试已存在。
2. 当前没有真实数据库与浏览器端到端联调测试，现阶段主要是 Service、Controller 契约和 Vue 组件测试。
3. 覆盖率验收需等待现有失败项修复后重新生成，不能以红灯测试下的覆盖率作为阶段通过依据。

## 4. 后续回归规则

1. 功能负责人每修复一个缺陷，先运行对应失败测试，再运行同模块测试。
2. 修复提交不得删除、跳过或弱化既有断言；若契约确需变更，应先评审并同步修改 SRS、接口文档和测试。
3. 最终执行前后端全量回归，目标为零失败、零未处理异常。
4. 测试专员只维护用例、回归证据、缺陷和需求影响记录，不代写核心业务实现。
