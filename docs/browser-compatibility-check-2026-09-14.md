# 第二阶段浏览器与移动视口专项记录（2026-09-14）

## 范围与环境

- 基线：SRS V2.0 的 NFR-007 与 `docs/api-contract-v2.md` 的页面视口约定；前端 Vite、本地后端及 PostgreSQL 16 演示数据均已启动。
- 实测浏览器：Codex 应用内浏览器。它不能代表 Chrome、Edge 或 Firefox 的兼容性结论。本机仅发现 Edge 可执行文件，但本次未在 Edge 中完成可控视口验收；Chrome 和 Firefox 未安装。
- 检查方法：打开实际页面，核对加载结果与控制台，并比较 `document.documentElement.scrollWidth` 和 `window.innerWidth`；管理员表格另检查末列操作按钮的位置。横向溢出判定为前者大于后者。
- 浏览器会话使用本地演示账号；未进行新增、修改或删除业务数据的操作。临时测试页已关闭，视口已恢复。

## 缺陷：移动端管理员用户列表横向溢出

- 编号：`UI-MOBILE-001`；对应 `P3-UI-004`、`P3-NFR-007`；状态：待页面负责人修复并回归。
- 前置：本地服务与演示数据可用，以管理员身份登录。
- 复现：将应用内浏览器视口设为360×844或390×844，进入 `/admin`，保持默认“用户”页签且列表至少有一条记录。
- 预期：列表和“禁用/启用”操作在视口内可见、可操作，页面不产生横向滚动。
- 实际：表格右边界为415px，390px视口时末列按钮右边界约403px；页面出现横向滚动，截图中操作列被挤到屏幕外。360px时溢出55px，390px时溢出25px。
- 定位线索：`frontend/src/views/Admin.vue` 的 `.admin-table` 使用普通表格布局，用户表头只有4列，而数据行另含操作列；最小内容宽度超过窄屏容器。此项是界面缺陷记录，尚未修改业务/页面实现。
- 回归要求：页面负责人修复后，在360、390、430、520及1280px复测用户、商家、商品、订单、退款页签；核对操作按钮可见可点、无横向溢出和控制台错误，并留存截图。
