## 自动化维护规则

1. 新业务页面首次提交前，由测试人员先把对应场景写成失败测试。
2. API 请求使用 Mock 验证 URL、方法、请求体、Token 和查询参数。
3. 页面测试覆盖加载中、成功、空数据和失败四种状态中的适用项。
4. 前端不重新计算可信金额；断言以接口返回的小计、总价和订单金额为准。
5. “待功能”项由功能负责人完成业务入口后，测试人员再补充具体交互用例。
