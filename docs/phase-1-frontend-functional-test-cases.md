## 自动化转换规则

1. 页面或公共模块首次提交前，测试人员先把对应“待页面实现”用例写成失败测试。
2. API 请求使用 Mock 验证 URL、方法、请求体、Token 和 Query 参数。
3. 页面测试至少覆盖加载中、成功、空数据和失败四种状态中的适用项。
4. 不在前端重新计算可信金额；断言以接口返回的小计、总价和订单金额为准。
5. 全部业务页面完成后，本表不得继续存在无原因的“待页面实现”条目。
