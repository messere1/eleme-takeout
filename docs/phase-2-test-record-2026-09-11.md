## 4. 风险覆盖

- 价格指数形式、三位小数、零/负值、超范围和非数字。
- 四角色跨角色访问、资源越权、管理员列表脱敏。
- 购物车用户/店铺隔离、收货快照、关店/缺货、重复提交。
- 支付截止、自动取消入口、库存回补幂等、支付/取消50并发竞争。
- 退款累计上限、50并发额度竞争、终态幂等、商家归属和管理员权限。
- 骑手50并发原子领取、本人任务、配送状态；注销后登录阻断和手机号释放结构。
- 图片类型/魔数/5MiB/授权/随机名/关联失败清理。
- 400/401/403/404/409/500 的 `traceId` 和敏感信息保护。

Docker Hub 拉取镜像时出现网络超时，本次使用 DaoCloud 镜像代理取得官方 PostgreSQL 16 镜像，并在本地标记为 `postgres:16`；项目配置本身仍使用官方镜像名，不绑定特定代理。

2026-09-12 重新进入联调环境时，确认 WSL2 在没有常驻进程后会被系统自动回收，容器随之停止，后端首次启动出现数据库连接拒绝。恢复 WSL 常驻进程并启动容器后，PostgreSQL 健康检查再次通过、重启次数为0，后端成功取得 `PgConnection`。该问题属于本机开发环境生命周期，不计为业务缺陷；演示前须先确认数据库健康再启动后端。

同日合并远端改动后，数据库宿主端口由5432调整为15432；旧容器仍保留原端口映射，导致新版后端首次连接失败。保留命名数据卷并按最新 `compose.yaml` 重建容器后，15432端口映射、数据完整性和健康检查均通过，四角色真实权限矩阵复测结果保持不变。
