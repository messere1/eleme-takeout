# 第一阶段需求基线

第一阶段按 SRS V1.2 的 P0 范围实施：FR-001～FR-018、FR-020、FR-021。FR-019（取消订单）保留到第二阶段；`ACCEPTED`、`COMPLETED` 等额外状态在登记并评审需求变更前不计入本阶段基线。

## TDD 提交规则

每个功能必须按以下顺序留下独立 Git 证据：

1. 分析单个功能和验收场景；
2. 编写并运行失败测试；
3. 单独提交失败测试；
4. 编写使测试通过的最小实现；
5. 运行当前功能测试和全量回归测试；
6. 单独提交实现；
7. 如需重构，再提交不改变外部行为的独立重构。

测试提交统一使用 `test(FR-xxx): ...`，实现提交统一使用 `feat(FR-xxx): ...`。
